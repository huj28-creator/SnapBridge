# Support

For setup help or bug reports, use [GitHub Issues](https://github.com/huj28-creator/SnapBridge/issues). Include ShotSkiff version, macOS/iOS version, Mac architecture, and repeatable steps. Do not attach personal photos, device identifiers, pairing codes/tokens, signing profiles, or Apple account information.

Start with the [Mac guide](docs/install-mac.md), [iPhone companion guide](docs/install-iphone.md), and [renewal notes](docs/renewal.md). The two install paths have different requirements.
