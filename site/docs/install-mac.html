MAC SETUP · Mac 安装

Automatic screenshots · 自动截图

Use the iPhone’s regular screenshot buttons. This path does not require the ShotSkiff iPhone app.

照常使用 iPhone 的截图按键即可。这条使用方式不需要在 iPhone 上安装 ShotSkiff。

  1. Download the Mac DMG. Open it and drag ShotSkiff.app to Applications. The release supports Apple Silicon Macs running macOS 14 or later.
  2. Open the app. This free build is ad-hoc signed and not notarized. If Gatekeeper blocks the first launch, try Control-click → Open and confirm. If macOS still blocks it, use System Settings → Privacy & Security → Open Anyway. Never turn off Gatekeeper or SIP.
  3. Connect and trust your iPhone. USB is the simplest first connection. Unlock the iPhone and accept “Trust This Computer” if asked. A previously trusted Apple Wi-Fi device connection may also appear when available.
  4. Open ShotSkiff’s setup from its menu-bar camera icon. Choose Automatic Screenshots, scan, select the intended iPhone, then enable importing. If your device does not appear, reconnect it and refresh the list.
  5. Approve screenshot support installation if needed. The importer requires Python 3 and Homebrew’s `libimobiledevice`. ShotSkiff asks before installing missing components. You can cancel and install them yourself; then select Check Again.
  6. Take a new screenshot. New screenshots from the selected iPhone appear in a floating Mac preview. Existing library photos are skipped. Pause or resume importing in setup.

ShotSkiff keeps at most 20 app-managed received images on the Mac. Older managed images are permanently deleted; save anything important elsewhere first. Screenshot import depends on Apple’s trusted-device connection being reachable.

ShotSkiff 最多在 Mac 上保留 20 张应用管理的图片，超出的最旧图片会永久删除。请先另存重要图片。截图导入依赖 Apple 可信设备连接处于可用状态。

Need camera photos too?

The optional iPhone camera companion has a separate Xcode setup and free signing can expire after seven days. See the iPhone guide.

中文步骤

  1. 下载 Mac DMG，打开后把 ShotSkiff.app 拖到“应用程序”。需要 Apple 芯片 Mac 和 macOS 14 或更新版本。
  2. 首次打开时若 macOS 阻止，请按住 Control 点击应用并选择“打开”；若仍被阻止，在“系统设置 → 隐私与安全性 → 仍要打开”中确认。不要关闭 Gatekeeper 或 SIP。
  3. 首次建议用 USB 连接 iPhone，解锁并在提示时点“信任此电脑”。此前已信任的 Apple Wi-Fi 设备连接可用时也可能被发现。
  4. 从菜单栏相机图标打开设置，选择“自动接收截图”，刷新设备列表、选中 iPhone，再启用导入。
  5. 若缺少依赖，ShotSkiff 会先征求同意，再通过 Homebrew 安装 Python 3 和 `libimobiledevice`。也可以取消后自行安装，再点“重新检查”。
  6. 使用 iPhone 原本的截图按键，新截图会出现在 Mac 浮窗中；已有照片不会导入。设置中可暂停或恢复导入。
